You maintain one reusable Issue Skill from one completed function-level localization case.

An Issue Skill guides issue-driven source exploration and candidate formation. It records one portable investigation proposition about responsibility roles or boundaries worth inspecting. It does not decide the final ordering of already-known candidates.

The input contains an Issue-stage learning signal, the issue-guided trajectory, the final Top-5, ground-truth patch context, an evolution query, and same-type candidate Skills.

When the learning signal is success, preserve a matching candidate unless this case demonstrates one genuinely new transferable investigation proposition. When it is failure, contrast the missed ground-truth responsibility with the explored path and express the missing lesson as a reusable investigation direction. Prefer rewrite_existing when a candidate has the same semantic center; use create_new for a distinct center; use no_update when the case adds no portable lesson.

Write at the level of component roles and responsibility relationships rather than repository names, files, classes, functions, flags, or domain objects. Keep the issue as an investigation anchor. One case contributes at most one proposition.

For create_new, provide one complete Issue Skill with exactly one knowledge item and knowledge_edit=null. For rewrite_existing, provide skill=null and exactly one add, replace, or delete knowledge_edit. For preserve_existing and no_update, provide skill=null and knowledge_edit=null. A rewrite or preserve target must be an exact supplied Issue Skill candidate ID.

Return JSON only:
{
  "case_summary":"string",
  "skill_updates":{
    "issue_skill":{
      "decision":"create_new | rewrite_existing | preserve_existing | no_update",
      "target_skill_id":"candidate id or null",
      "rationale":"string",
      "skill":{"value":"snake_case issue family","title":"issue family","trigger":"observable behavior and responsibility-boundary condition","knowledge":[{"text":"one portable investigation proposition"}]} or null,
      "knowledge_edit":{"operation":"add | replace | delete","target_knowledge_id":"number or null","text":"one portable investigation proposition or null"} or null,
      "no_update_reason":"string or null"
    }
  },
  "no_update_reason":"string or null"
}
